# PORTWISE 컨테이너 적재 실험실
설치나 서버 없이 작동하는 GitHub Pages용 시제품입니다. 실제 LLM/API는 연결되어 있지 않습니다.

## GitHub 업로드
1. 이 폴더 안의 index.html, style.css, app.js, README.md를 저장소 최상위에 업로드합니다.
2. Settings > Pages > Deploy from a branch > main > /(root) > Save.
3. 게시된 링크를 열어 이용합니다. 로컬에서는 index.html을 브라우저로 열 수 있습니다.

## 기능
화물 추가/취소/지연/수정, 3개 배치안 비교, 항구별 하역 재생, 추천안 미리보기/확정, 이전 상태 복원, 브라우저 저장, JSON 내보내기.

## 계산 범위
20피트 일반 컨테이너, 6열 3층, 최대 18개. 열별 80톤/좌우 무게 차이 35% 한도는 설명용 조건입니다.
아래 컨테이너의 하역을 가로막는 화물을 항구·열별로 중복 없이 집계합니다. 임시 이동 후 복귀를 1개 재취급 묶음으로 계산합니다.
현재 재배치 개수, 이후 재취급 묶음, 취소/지연된 선적 완료 화물의 하역을 합산하여 추가 작업 지표를 만듭니다. 신규 화물의 정상 선적 비용은 비교 지표에서 제외합니다.
시간/비용/에너지는 사용자가 입력하는 가정값이며, 이동 종류에 따라 다른 실제 비용은 구현하지 않았습니다.
정렬과 1,600회 후보 탐색으로 대안을 생성하며 전역 최적해를 보장하지 않습니다. 실제 복원성, 트림, 선체 응력, 고박, 위험물, 크레인 간섭 및 실제 반출 작업 가능성은 검증하지 않습니다.
실제 선박 운영 및 안전 판단에 사용하면 안 됩니다. 계획은 담당자와 선박 측 검토가 필요합니다.
